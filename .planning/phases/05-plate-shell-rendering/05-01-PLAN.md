<objective>
Close the D-07 gap surfaced in the Phase 4 demo: parse STAAD plate/shell elements into the model and render them. Today `ELEMENT INCIDENCES` / `ELEMENT PROPERTIES` are skipped with `SKIPPED_ELEMENT` warnings (938 elements in HPP_Main_Building_2.std alone), so slabs, walls, and mats are invisible. This plan adds a tolerant `elements.ts` handler pair (typed `Plate { id, nodes: [4], thickness? }` records), extends `StaadModel` with `elements`, renders all plates as one merged double-sided surface mesh in the scene, and surfaces a Plates count in the summary card.

Purpose: structural models routinely carry significant plate work (rafts, shear walls, deck slabs); a viewer that hides them misrepresents the model.

Output: `elements: Plate[]` on every parsed model, plate surfaces visible in the viewer, golden-fixture element count proven, zero regression to existing suites.
</objective>

| T-05-03 | DoS | Range rows (`1 TO 999999`) expand combinatorially | mitigate | Ranges are NOT expanded — they warn SKIPPED_ELEMENT per row (tolerant skip, PLATE-03) |
| T-05-04 | Tampering | Duplicate element ids silently corrupt thickness resolution | mitigate | First record wins; duplicates warn |
| T-05-SC | Tampering | npm installs | mitigate | None — pure parser/renderer code, zero new dependencies |
