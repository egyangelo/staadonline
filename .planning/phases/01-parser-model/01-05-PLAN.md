## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JOINT COORDINATES body → node records | Untrusted coordinates flow into float conversions; malformed rows must not crash or poison the model. |
| MEMBER INCIDENCES body → member records | Untrusted id lists drive range expansion — the allocation-bomb surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | DoS | range expansion (1 TO 999999999) | mitigate | expandList bounded by maxRef/hard cap before allocation (PITFALLS security: zip-bomb) |
| T-05-02 | Tampering | duplicate node/member ids | mitigate | Map-based dedupe keeps first, warns on collision; never plain-object keys (PITFALLS security) |
| T-05-03 | Integrity | coordinate unit conversion | mitigate | All coords via ctx.units toMeters only; stateful unit context per P1 |
| T-05-04 | DoS | float parsing of hostile numeric strings | mitigate | Strict numeric parse (Number() with NaN/Infinity rejection) — no eval, no regex-driven parsing |
| T-05-SC | Tampering | npm installs | mitigate | No installs in this plan (01-01 owns installs; checkpoint approved there) |
</threat_model>
