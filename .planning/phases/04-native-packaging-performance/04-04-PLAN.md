<objective>
Enhance the existing `LoadingOverlay` into a determinate progress overlay (D-07, PERF-02) and give `modelStore` an optional `progress` field so the worker relay (04-03) has a single source of truth. When a `fraction` is available (the >2 MB worker path) the overlay shows a determinate progress bar + percentage using the established glass tokens; for small/synchronous files it keeps the existing spinner (no bar flash). Accessibility preserved: `role="progressbar"`, `aria-valuenow/min/max`, `aria-live="polite"`, `aria-busy="true"`.

Purpose: PERF-02's "progress feedback for large files" needs both a place to store progress (store) and a way to render it (overlay). This plan delivers both, in parallel with the worker relay (04-03).

Output: `modelStore.progress` + an enhanced `LoadingOverlay` with a determinate bar, matching the app's glass language.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| modelStore.progress (worker relay fraction) → LoadingOverlay | A numeric [0,1] fraction becomes UI text (percentage) |
| fraction prop → aria-valuenow / width | Derived numeric attributes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-16 | Tampering | Non-numeric / out-of-range fraction renders as text | mitigate | fraction is typed `number \| null`; pct derived via `Math.round(fraction * 100)`; the worker throttles to [0,1] and parser caps at 1.0 |
| T-04-17 | Information Disclosure | Progress leaks file structure | mitigate | Progress is a fraction only — no filename/content in the overlay; matches privacy positioning |
| T-04-18 | Tampering | aria-valuenow outside 0-100 breaks AT | mitigate | aria-valuemin=0 / aria-valuemax=100 hard-coded; now = clamped pct (0-100) |
| T-04-19 | DoS | Frequent store writes from progress spam | mitigate | worker throttle ≥1% delta (04-03) bounds setProgress frequency; setProgress is a single atomic zustand set |
| T-04-20 | Tampering | CSS/JSX injection via progress string | mitigate | percentage rendered as a React text node (`{pct}%`) — never dangerouslySetInnerHTML (T-02-01) |
| T-04-SC | Tampering | npm installs | mitigate | None — existing zustand/React/CSS only |
</threat_model>
