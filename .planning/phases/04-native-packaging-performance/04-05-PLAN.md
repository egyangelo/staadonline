<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repo → Android native project | Generated android/ is committed; signing secrets must never enter it |
| Web static bundle → Android assets | Bundled JS/CSS is served by the local WebView server (offline origin) |
| build scripts → gradle | next build → cap sync → gradle order determines what ships |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-21 | Tampering | Keystore / signing password committed | mitigate | `*.jks` + `keystore.properties` git-ignored; passwords via env/ignored file; check-ignore verified in Task 4 acceptance |
| T-04-22 | Tampering | AGP 9 upgrade breaks proguard | mitigate | variables.gradle pinned to AGP 8.13.x; proguard-android-optimize.txt; no Studio AGP-9 acceptance (R-2) |
| T-04-23 | Information Disclosure | App sends user files off-device / telemetry | mitigate | Static export is self-contained (grep no external fetch); only the local convertFileSrc read; privacy positioning (no telemetry) |
| T-04-24 | Tampering | Stale bundle ships (cap sync before build) | mitigate | Scripts enforce next build → cap sync → gradle order (R-4); Task 6 re-syncs |
| T-04-25 | Tampering | basePath/assetPrefix breaks local serving | mitigate | basePath/assetPrefix left '' (defaults); served under local WebView origin (D-09) |
| T-04-26 | DoS | Capacitor 9 / unsupported stack | mitigate | Pinned ^8.5.0; cap --version verified 8.x |
| T-04-SC | Tampering | Unpinned dependency installs | mitigate | All @capacitor/* pinned to 8.x; Capawesome file-picker pinned to current stable |
</threat_model>
