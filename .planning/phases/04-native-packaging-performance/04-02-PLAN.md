<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-picked file (untrusted `.std` content + filename) → readNativeFile | Filename drives extension guard; content becomes `text` handed to the parser |
| content:// URI → Capacitor.convertFileSrc → fetch | Local WebView server path; fetch never touches the network |
| picked.blob / probed size → guard | Size drives the TOO_LARGE guard ordering |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | DoS | Oversized read OOM (PLAT-03 vector) | mitigate | Streaming blob path (never base64); TOO_LARGE guard fires on a probed size BEFORE blob.text() materializes (FILE-04, R-5) |
| T-04-06 | Tampering | Raw content:// fetch fails / wrong-scheme | mitigate | Always `Capacitor.convertFileSrc(path)` first (R-3); never `fetch('content://…')` |
| T-04-07 | Information Disclosure | File content exfiltration | mitigate | fetch is to the LOCAL WebView server (`http://localhost/_capacitor_file_/`) — no remote URL; matches privacy positioning (no telemetry) |
| T-04-08 | Tampering | Cancel leaves corrupt state | mitigate | `if (!picked?.name) return undefined` — no beginLoading, no store write, no error (FILE-03 strict no-op) |
| T-04-09 | DoS | Read throw unhandled | mitigate | Read/fetch wrapped in `FileServiceError UNREADABLE` (existing pattern) |
| T-04-SC | Tampering | npm installs | mitigate | Runtime deps (`@capacitor/core`, `@capawesome/capacitor-file-picker`) installed once by 04-05; no additional installs here |
</threat_model>
