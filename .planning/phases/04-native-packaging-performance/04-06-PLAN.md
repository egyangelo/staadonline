<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native picker file (untrusted .std content/name) → readNativeFile → parseModel | File bytes + filename cross the Capacitor boundary into the parser |
| worker progress/result → main thread → stores → UI | Structured-cloned model + numeric fraction reach the renderer/overlay |
| Signed APK/AAB → device | Build secrets and bundled user-file data |
| Bundled static export → local WebView origin | Offline serving; no network origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-27 | Tampering | Repeat-open stale worker result commits | mitigate | openToken guard after every await (unchanged commit discipline) ignores stale worker result; singleton worker not killed (04-03) |
| T-04-28 | Tampering | Picker cancel corrupts state | mitigate | NativeOpenControl returns on `!files?.length`; readNativeFile returns undefined; no beginLoading/store/error (FILE-03) |
| T-04-29 | Information Disclosure | User file leaves device / telemetry | mitigate | Only local convertFileSrc read; static bundle self-contained; grep-verified no external fetch; privacy positioning |
| T-04-30 | DoS | Large-file parse blocks main thread (PERF-01 regress) | mitigate | Worker genuinely spins up (R-1 verified, webpack fallback); never silent main-thread for >2 MB; 64 MB cap bounds input |
| T-04-31 | Tampering | Signing secrets leaked to device artifact | mitigate | Release signing from git-ignored keystore.properties; release cert verified; keystore untracked |
| T-04-32 | Tampering | Bundled stale JS ships (cap sync order) | mitigate | Task 5 enforces next build → cap sync → gradle (R-4) |
| T-04-SC | Tampering | npm installs during verification | mitigate | None — verification reuses pinned deps; only `next build --webpack` flag change if R-1 forces it |
</threat_model>
