# Phase 3 — UI Design Contract (Interaction & Visualization)

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **Extends the Phase 2 contract** (02-UI-SPEC, approved 2026-08-16). Same Apple-style fluid chrome, same token set, same manual CSS-Module stack. This contract re-specifies **nothing** that Phase 2 locked; it adds the color-mode, marker/load, inspection, and expanded-summary surfaces with new tokens declared **only where Phase 2 had no value** (categorical palettes, marker/arrow/dim/marker colors, glyph geometry constants).

| Property | Value |

Registry safety gate: not applicable.

## Typography

Exactly 4 sizes, exactly 2 weights (Phase 2 scale, new roles mapped on). Size-specific tracking, line-height tracks size inversely — both unchanged rules.

| Role | Size | Weight | Line Height | Tracking | Usage |
|------|------|--------|-------------|----------|-------|
| Caption | 12px | 400 | 1.4 | +0.06em | Uppercase labels, segmented-control labels ("SECTION · GROUP"…), marker/labels/marker toggles, legend chip, popover field labels (SECTION, GROUP, LENGTH…), group headings, warning list captions |
| Detail | 14px | 400 | 1.5 | +0.01em | Mono IDs/coordinates/lengths/magnitudes ("MEMBER 34","12.500 m","12.5 KN"), load-case selector value, dropdown list rows, expanded-summary values |
| Body | 16px | 400 | 1.5 | 0 | Popover field values (section/group names), empty-group note ("No groups defined"), button labels |
| Heading | 24px | 600 | 1.15 | −0.018em | "Approximate dimensions" scaled down to badge size via Caption weight-bump (below) — **Heading reserved for popover MOI title? No:** popover title is mono Detail (source-id identity, per D-04). Heading stays Phase-2-assigned (empty-state + stat values). |

- **Mono variant**: `ui-monospace, "Cascadia Mono", Consolas, monospace` at **14px / 400 / 1.5** for IDs, coordinates, lengths, magnitudes, units, warning lines (Phase 2 rule).
- **Exception (admissible, additive):** load **magnitude labels** are small glass chips on dense arrows; they render at **12px mono / 400 / 1.4, tracking +0.01em**. Phase 2's "mono inherits 14px" scoped to file names/bounds/units; magnitude labels are new glyph layer and constraining them to 14px hurts dense-model read-back (D-09/D-10's whole point). This is the **only** new mono size.
- Vibrancy rule over translucent chrome: bump weight to 600 and tracking +0.01em over blurred glass (unchanged Phase 2 §Typography).
- Segmented-control labels: Caption 600 (bump for glass), `text-transform: uppercase`, tracking +0.06em.

### NEW — Categorical member palettes (D-01..D-04; Claude's discretion → fixed)

One **fixed, curated 8-hue palette** used by all three categorical modes. Values are mid-tone, high-chroma, hue-spaced ≥ ~44° for adjacent distinctness; each clears ≥ ~4:1 against `#0A0A0C` and reads on `#F5F5F7` under scene lighting. Theme-independent (one set for both light and dark).

| Index | Hue | Hex | Reads as |
|-------|-----|-----|----------|
| P0 | Green | `#2FA45C` | standard section/green |
| P1 | Violet | `#8B5CF6` | violet |
| P2 | Orange | `#F26D21` | orange |
| P3 | Cyan | `#0FB5D6` | cyan |
| P4 | Rose | `#E5484D` | rose/red |
| P5 | Amber | `#F0B429` | amber |
| P6 | Indigo | `#4C63F5` | indigo |
| P7 | Lime | `#7BC043` | lime |

- **Mode seeding (deterministic, so switching modes visibly changes a member's color):** by-section seeds at P0; by-group seeds at P3; by-material seeds at P5. Key assignment is **first-seen order** over `model.members` (iterate members, count distinct keys in encounter order), then `palette[keyIndex % 8]` — cyclic round-robin (D-02). Adjacent-file-order keys get adjacent hues, and the 8-slot cycle guarantees no collision between consecutive keys beyond the palette size.
- **Unassigned members (D-03):** in group/material modes, members with no `member.group` / `member.material` render **neutral grey `#8E8E93`** (one value, both themes). Never a palette slot.
- **"All members" mode (D-04):** every member is painted the **accent blue** — `#007AFF` in light theme, `#0A84FF` in dark (theme-aware). This is the clean selected baseline.
- **Render note for executor:** member material emissive is the same color at 8% intensity (dark-scene readability); diffuse is the palette color. No per-instance opacity tricks; dims/highlights use the color-buffer rewrite described in §Motion and the Inventory.

## Motion & Visuals (Apple-style, extends 02-UI-SPEC §Motion)

Springs throughout; every animation is interruptible and animates from the **live on-screen value** (Apple §3). Phase 2 motion table (chrome enter/exit, slider, dropzone, camera settle, model appear, drag-over ring) is **unchanged**. New rows:

| Interaction | Damping | Response | Notes |
|-------------|---------|----------|-------|
| Color-mode palette switch | (snap) | — | Per-instance color buffer rewrite is **instant** (COLOR-04 must not animate thousands of instance colors at frame rate). The **control** itself animates: segment thumb slides with a spring 1.0/0.30s from its current position; scene colors swap the same frame the control commits. Reduced-motion unaffected (no motion to reduce) |
| Marker layer toggle (supports+loads) | 1.0 | 0.35s | Whole layer materializes: translateY 8→0 + scale 0.98→1 + opacity + `backdrop-filter` blur 0→20px together on the DOM chrome; the 3D glyph group fades via material opacity 0→1 (one shared opacity on the layer material). Reverse on off, same axis |
| Inspector popover slide-in | 1.0 | 0.40s | From right edge: translateX 24→0, scale 0.98→1, opacity, blur materialize (§12). Same axis on dismiss (→ +24px). Interruptible — a second tap re-targets from the live transform |
| Expanded summary (D-16 continuity) | 1.0 | 0.45s | The card's width/height animates from **its current live size** (read presentation size on interrupt, never target — §3); new sections fade in with translateY 8→0, staggered 30ms as space appears. Collapse folds in reverse from live size. This is the one surface that must read as **continuous growth, never a swap** |
| Load-case dropdown open | 1.0 | 0.25s | max-height 0→320px + opacity + translateY −4→0 from live value; rows have no per-row stagger (list density). Close on outside tap reverses |
| Magnitude-label chips toggle | 1.0 | 0.15s | Chips scale 0.96→1 + opacity; cheaper spring, info-density layer |
| Legend chip text change | 1.0 | 0.15s | Cross-fade mono text (150ms), chip stays put |
| Member hover dim/brighten | (snap, throttled) | — | ColorLayer rewrites on the 8 Hz hover tick; the dim/brighten **is** the transition (no lerp on GPU — cost). Dim-others+brighten (chosen over selected-only per CONTEXT discretion): hovered instance lerps toward `#FFFFFF` by **25%**; every other member lerps toward `#6E6E73` by **48%**.
