| Support type/releases (untrusted) → glyph selections | Glyph shape chosen by file data |
| targets/length counts → instanced sizes | Rebuild loops bounded by supports/members counts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | Load magnitude/unit label injection | mitigate | formatMagnitude/formatDistributedMagnitude constrain units to the UnitForce/UnitLength unions; magnitudes Number-formatted — no raw strings |
| T-03-02 | DoS | Glyph/instance explosion | mitigate | per-glyph fixed tessellation (03-03), distributed count clamped 2..12, instances bounded by supports.length + targets.length; P5 dispose on every rebuild kills leaks |
| T-03-03 | Tampering | Support type switch on file string | mitigate | buildSupportGlyph switches on closed SupportType union — buildLoadGlyph on closed LoadKind (both 03-03) |
| T-03-04 | Tampering | Marker material color injection | mitigate | material colors are fixed in-code constants (#636366/#A1A1A6/#F5A623), never data-driven |
| T-03-05 | DoS | Label chip explosion | mitigate | chips only while labelsVisible; count bounded by item/segment counts; drei Html zIndex kept at 0 |
| T-03-06 | Tampering | Rebuild retention | mitigate | dispose-first in every rebuild effect + cleanup on unmount (P5) |
| T-03-SC | Tampering | npm installs | mitigate | no installs (drei Html already pinned in Phase 2 stack) |
