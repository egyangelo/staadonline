## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pointer event stream (user input) → raycast/hover/selection | Rapid move events hit the throttle + guard logic |
| Model instance→member map → selection ids | Throttled raycast resolves instance to (potentially untrusted) ids |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | DoS | Pointer-event flood on dense models | mitigate | 125ms hover throttle caps raycast rate (D-14); NO_TAP guard suppresses tap spam; hover cleared on leave/zoom |
| T-03-02 | Tampering | instance→member map id drift | mitigate | maps are built once by SceneBuilder (02-04) from the write-once model; raycast only looks them up — no re-parse |
| T-03-03 | Tampering | Buffer writes on wrong mesh | mitigate | applyModeColors walks only the provided meshes + instanceToMember (closed pair from SceneBuilder) |
| T-03-04 | Tampering | Tap registration from drag/zoom | mitigate | dragDistanceExceeded + NO_TAP guard veto; camera untouched |
| T-03-05 | Tampering | Cache poisoning across themes | mitigate | modeColorCache keyed `${mode}:${theme}` (bounded at 8 entries), capacity guards in 03-01 cache |
| T-03-06 | DoS | Hover re-write every frame | mitigate | hover committed inside the 8 Hz throttle only (picking.ts) |
| T-03-SC | Tampering | npm installs | mitigate | no installs (three + R3F pinned, no new deps) |
</threat_model>
