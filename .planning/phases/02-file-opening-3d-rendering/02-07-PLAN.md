<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page.tsx ↔ FileService | File bytes and metadata cross into the app at readStdFile; page layer must not re-derive guards or trust file names |
| modelStore (untrusted-derived) → page rendering | All strings shown in the EMPTY/LOADED chrome derive from parsed file content |
| user gesture → open pipeline | Picker cancel / empty drop / repeat-open are adversarial-ish UI states that must not corrupt state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | XSS via file name / warnings | mitigate | all file-derived strings rendered as React text nodes in page chrome (never dangerouslySetInnerHTML); names are display data only |
| T-02-02 | DoS | oversized file before parse | mitigate | rejection happens inside readStdFile BEFORE parseStaad via MAX_INPUT_LENGTH + extension guard; page never allocates the text |
| T-02-03 | Tampering | cancel / partial commit | mitigate | picker cancel no-ops by construction; abort flag prevents aborted in-flight opens from committing setModel (FILE-03); EMPTY restored on error |
| T-02-04 | DoS | drag-drop event flood | mitigate | window onDrop/dragOver preventDefault only; readStdFile is async single-file (files[0]); no unbounded accumulation |
| T-02-05 | Information Disclosure | privacy guarantee | mitigate | page performs zero network calls; parse/model/stores stay local; no model-content telemetry |
| T-02-06 | Tampering | repeat-open race | mitigate | in-flight open aborted before a new one starts; setModel called once per completed read with an abort check between await points |
| T-02-SC | Tampering | npm installs | mitigate | No installs in this plan |
</threat_model>
