## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| StaadModel (from untrusted `.std`) → SceneBuilder | Nodes/members/sections/rotation values from attacker-controlled files become geometry, matrices, and GPU buffers |
| SceneBuilder → GPU | Instance matrices and geometry positions leave the CPU as Float32 buffers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | DoS | draw calls / instance count | mitigate | one InstancedMesh per distinct section (bounded by sections.size, not members.length); PITFALLS P4 budget `render.calls < 100` asserted in build test |
| T-02-02 | Tampering | NaN / Infinity coords | mitigate | rebase produces finite offsets; instance matrix math guarded by Vector3 arithmetic; computeCameraFit returns finite near/far even for degenerate bounds (tested) |
| T-02-03 | DoS | GPU memory across loads | mitigate | SceneBuilder.dispose() during model replace + unmount disposes geometry/material and drops maps (P5); geometry cache keyed per distinct label |
| T-02-04 | Tampering | rotation injection | mitigate | `member.rotation` is a finite number from 02-01 (already validated); converted to radians with a clamp; never a raw string reaching matrix math |
| T-02-05 | Tampering | XSS via member data | mitigate | scene is pure three data (no DOM); all model-derived strings render later via React text nodes only |
| T-02-06 | DoS | instance matrix explosion | mitigate | instanceCount = member count is the intended scale; matrices built once at build, `needsUpdate` only on change — never per frame (ARCHITECTURE perf rules) |
| T-02-SC | Tampering | npm installs | mitigate | No installs in this plan |
</threat_model>
