<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model store strings (untrusted `.std` content) → StatsSummary | Section labels, file names, warning messages from attacker-controlled files are rendered as text |
| FileService typed errors → ErrorToast | Error codes/copy are contract constants, but the wrapped thrown message may echo file content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | XSS via rendered model strings | mitigate | every displayed value rendered as React text node — no dangerouslySetInnerHTML (grep-gated in verification); section/file names are display data never parsed as markup |
| T-02-02 | Tampering | XSS via error message echo | mitigate | ErrorToast shows a FIXED copy per code; the wrapped parse message is appended as React text with a length cap, never as HTML |
| T-02-03 | DoS | picker mis-fires | mitigate | onChange only fires on a selected file; input.value reset allows re-pick; cancel path structurally cannot dispatch (FILE-03) |
| T-02-04 | Information Disclosure | privacy guarantee | mitigate | chrome performs no network; no model-content analytics (privacy is the product — PITFALLS security) |
| T-02-05 | Tampering | malicious section count | mitigate | approximate count is derived from `approximate === true` booleans only (no string parsing); count clamping at render is trivial and safe |
| T-02-SC | Tampering | npm installs | mitigate | No installs in this plan |
</threat_model>
